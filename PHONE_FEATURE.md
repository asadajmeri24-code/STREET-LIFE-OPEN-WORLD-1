# LIFE STREET – Working Phone Feature (V1)

## 📱 App Icons
- **InstaStreet** (Instagram-style posts & reels)
- **Reels Studio** (Reel banana, caption/effect add karna, post karna)
- **Chats** (Taiyaba, Aman, Faizan, Talha, Sahal ke saath messaging)
- **Call** (Calling screen, ring/call audio, contacts)
- **Extras** (Gallery, notifications, basic settings)

## 🎬 Reel Creation Flow
1. Reel create button tap karo
2. Clip/scene select ya record karo
3. Caption/tag add karo
4. Post karke feed/reels mein show karo

## 💬 Chat & 📞 Call Flow
- **Chat:** Friend chuno -> message likho -> send karo -> conversation save rahe
- **Call:** Friend chuno -> call start karo -> active call screen + sound/voice feedback -> end call
